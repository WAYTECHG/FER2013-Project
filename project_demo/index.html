01 / BEHIND THE PROJECT

Learning the language
of facial expressions.

This XMUM deep learning project compares a custom convolutional neural network with VGG16, ResNet50, and MobileNetV2 on FER2013. Each model predicts seven expression classes from a 48 × 48 RGB face crop.

Explore the saved evaluation plots, then try an image or your webcam. Faces are located first; the trained classifier then scores each expression.

Locate face/Resize & normalize/Predict 7 classes

Predictions describe visual expressions and can be wrong. They do not establish how a person feels.
