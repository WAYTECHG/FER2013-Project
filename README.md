# Facial Expression Recognition on FER2013

Facial expression recognition using a custom CNN and three transfer learning models: VGG16, MobileNetV2, and ResNet50. The project combines model training and evaluation with a browser demo for image uploads and live webcam inference.

**[Open the live demo on Hugging Face Spaces →](https://huggingface.co/spaces/Wizzas/Face-Expression-Recognition)**

[![Live demo](<https://img.shields.io/badge/Hugging%20Face-Live%20Demo-FFD21E?logo=huggingface&logoColor=black>)](https://huggingface.co/spaces/Wizzas/Face-Expression-Recognition)

## Overview

The models classify seven facial expressions: **Angry, Disgust, Fear, Happy, Neutral, Sad, and Surprise**. Each classifier accepts a **48 × 48 RGB** face crop normalized by dividing pixel values by **255**, and returns seven softmax probabilities.

The research notebooks cover training, model comparison, and interpretation. The static interface makes the trained models accessible through image uploads and a webcam, with predictions performed locally in the visitor's browser.

## Live demo

- Upload JPG, JPEG, PNG, or WEBP images and select **Analyze image**.
- Start the webcam to display face boxes, predicted expressions, and confidence scores.
- Inspect the seven-class probability profile and select a detected face when several are present.
- Switch between available trained models; Custom CNN is the default used by the original desktop demo.
- Explore report benchmarks, confusion matrices, classification reports, ROC curves, and Grad-CAM figures.
- Send questions through the contact form when its Formspree endpoint is configured.

Camera permission is required for webcam input. If the embedded Space blocks camera access, use **Open full page for camera access** in the interface. Image and camera inference stay in the browser; contact messages are submitted to Formspree.

## Reported results

The demo's benchmark cards use the submitted project report, **Table 4.2.1, page 60**. These are recorded results, not a new evaluation of the deployed browser application.

| Model       | Approach                        | Reported test accuracy |
| ----------- | ------------------------------- | ---------------------: |
| Custom CNN  | Custom convolutional network    |       **66.00%** |
| ResNet50    | Residual transfer learning      |                 61.23% |
| MobileNetV2 | Lightweight transfer learning   |                 60.34% |
| VGG16       | Convolutional transfer learning |                 60.13% |

Evaluation includes class-wise precision, recall, and F1-score, confusion matrices, one-vs-rest ROC/AUC, and Grad-CAM visualizations. Saved evaluation figures are available in [the demo&#39;s results assets](project_demo/assets/results/). Grad-CAM is generated by the research notebooks; the browser demo displays the saved figures.

## Run the browser demo locally

From the repository root, run:

```powershell
py -m http.server 8000 --directory .\project_demo
```

Open [http://localhost:8000](http://localhost:8000) and keep the terminal running. Serve the app over HTTP/HTTPS rather than opening `index.html` directly. Running the static demo does not require TensorFlow or a Python inference server.

Keep the complete `project_demo` folder together, including `styles.css`, `config.js`, `core.js`, `vendor/`, `models/`, and `assets/`. The browser models use `.onnx` files with matching `.json` metadata; original `.keras` files are not needed for static hosting.

The original notebooks use TensorFlow/Keras, NumPy, Matplotlib, Seaborn, scikit-learn, and tf-keras-vis. The desktop demo also uses OpenCV. Set up a separate environment for research work:

```powershell
py -3.11 -m venv .venv-research
.\.venv-research\Scripts\python.exe -m pip install tensorflow opencv-python numpy matplotlib seaborn scikit-learn tf-keras-vis
```

Review and update dataset and checkpoint paths in the notebooks before running them. `main.py` contains machine-specific paths that must be changed to your own face detector, `CNN_best.keras`, and test image locations.

## Dataset and preprocessing

The project uses the [FER2013 dataset](https://www.kaggle.com/datasets/msambare/fer2013), organized into `fer2013/train/` and `fer2013/test/`. Each split contains the class folders `angry`, `disgust`, `fear`, `happy`, `neutral`, `sad`, and `surprise`. Follow the notebooks' validation setup when reproducing training.

All classifiers use RGB values divided by 255. Preserve this preprocessing and class order when exporting or replacing a model. The browser uses MediaPipe BlazeFace for localization; the original desktop script uses an OpenCV Haar cascade. Their detected face crops can differ, so predictions need not match on every scene.

## Limitations

FER2013 classifiers predict visual expression categories rather than a person's internal emotional state. Accuracy depends on lighting, pose, face visibility, and how closely the input resembles the training data. Reported benchmark accuracy does not guarantee the same performance on webcam footage. Browser analysis rates vary by device and model; Custom CNN is the recommended starting point for live use.
